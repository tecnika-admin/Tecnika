Polizas de nómina

  • Se puede configurar como se generan las pólizas: por procesamiento o por nómina. También se pueden compactar las pólizas agrupando la información.


  • Se configuran las cuentas contable a nivel de reglas salariales. Se pueden configurar por empleado, departamento o puesto de trabajo.


  • En la sección de contabilidad de la nómina aparece la póliza creada.


  • La póliza contiene los conceptos de nómina y las cuentas contables configuradas
